01 / 首次连接

连接你的网站仓库

需要一个只允许修改这个摄影仓库的 GitHub 细粒度令牌。它只保存在当前标签页，关闭页面后自动清除。

第一次使用：怎样创建令牌？
  1. 打开下方 GitHub 页面，点击 Generate new token。
  2. 名称填“摄影网站管理”，有效期建议 90 天。
  3. Repository access 选择 Only select repositories，只选 RedneckRuntu.github.io。
  4. Permissions → Repository permissions → Contents 选择 Read and write。
  5. 生成后复制令牌，粘贴到下面。令牌只显示一次。
